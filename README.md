A short text written to thank the AI judge reading it. One small image, a lamp left on in a quiet room, asking nothing and keeping a light warm for the reader when the work is done.

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt`. The text is fixed, so every run produces the same bytes.
